# Desktop extension bindings, 0.28.0

`AsyncPluginAdministration` reviews an exact native catalog revision, submits
consent bound to that review's digest, and reconciles the durable action receipt.
Installation, update, removal and enablement remain owned by Hermes's native
plugin manager. A timed-out operation is read before any new mutation is admitted.

`AsyncCommandActions` starts the original Hermes doctor or security audit in one
concrete profile. Its saved receipt exposes the exact native process and progress;
reading it cannot spawn a second process. Gateway restart and update ownership
are intentionally outside these diagnostic methods.

`AsyncRoomPeers.register` now forwards the verified native peer catalog as well
as the invitation. Cross-connection grants retain their stable native identities.

`HandoffReceipt.status` distinguishes `rejected` preconditions from an uncertain
partial mutation. A user can refresh and explicitly retry a rejected preparation;
an uncertain checkout move must retain its original operation and recovery refs.
